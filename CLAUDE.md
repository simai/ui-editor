# SIMAI Editor

Reference page editor for SIMAI Framework and SIMAI Pro. Read `README.md` and
`docs/STATUS.md` first.

- Never write components here: order them from `simai/ui-source` (universal) or
  `simai/ui-pro` (editor parts). Screens are assemblies.
- Pin exact Framework and Pro releases; never `latest` or `main`.
- English in code, commits and docs; interface text RU/EN through dictionaries.
- No secrets, `.env`, real customer content or local paths in the repository.
- The prototypes are behaviour references only.
